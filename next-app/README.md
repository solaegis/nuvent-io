# Nuvent SaaS App (Secret Beta)

This is the new dynamic SaaS application for Nuvent.io. It is currently being developed in this subdirectory to keep the main Hugo site active.

## Getting Started

1.  **Install dependencies**:
    ```bash
    npm install
    ```

2.  **Run the development server**:
    ```bash
    npm run dev
    ```

3.  **Open the app**:
    Navigate to [http://localhost:3000](http://localhost:3000).
    -   **Landing Page**: `/`
    -   **Pricing Page**: `/pricing` (Matches Claude design)

## Tech Stack

-   **Next.js 15+ (App Router)**
-   **Styling**: CSS Modules + Global CSS Variables (Premium Dark Theme)
-   **Fonts**: Inter (Sans) + Playfair Display (Serif)
